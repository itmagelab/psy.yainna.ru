# Фотографии

Сюда кладутся фотографии специалиста. Пока файл не назван в контенте,
на сайте показывается фирменная заглушка (`FigureGround.astro`).

## Как добавить

1. Положите файл в эту папку: `portrait-main.jpg`, `portrait-about.jpg`,
   `certificate-1.jpg` — имя любое, латиницей.
2. Укажите имя в контенте:

```yaml
photo:
  src: portrait-main.jpg
  alt: Портрет Анны Волковой
  width: 1200
  height: 1500
  position: 50% 30%
```

3. `npm run build` — Astro оптимизирует снимок сам: AVIF и WebP, несколько
   размеров под разные экраны, отложенная загрузка. Главное фото грузится
   сразу и с пометкой высокого приоритета.

Сертификаты подключаются так же, только в секции `education.md`:

```yaml
certificate:
  src: certificate-1.jpg
  alt: Диплом о переподготовке
  width: 1000
  height: 1400
```

## Требования к снимкам

- Оригинал: не менее 1600px по короткой стороне, JPEG или PNG, до 5 МБ.
- Портрет — вертикальный, 4:5 (`width` / `height` в YAML описывают кадр целиком,
  браузер просто вписывает изображение в этот бокс).
- Не обрабатывать снимки тяжёлыми фильтрами: зерно и «пластиковый» цвет
  разрушают ощущение живого человека.
- Никаких стоковых изображений и лиц не из этой съёмки.
- `position` задаёт, где в кадре находится лицо: `50% 30%` — ближе к верхней
  трети. По умолчанию `50% 35%`.
- `alt` пишется по-русски и осмысленно: «Портрет Анны Волковой»,
  «Анна Волкова в кабинете». Если фотография чисто декоративная —
  оставьте файл без `src`, и компонент нарисует заглушку.
